# El mapa de lo que no se mide

Visualización interactiva sobre el estado de actualización de los conjuntos de datos abiertos del Estado nacional argentino ([Datos Argentina](https://datos.gob.ar)), presentada al concurso **Contar con Datos** (UdeSA).

**Ver la visualización:** https://gerardoaboulafia.github.io/el-mapa-de-lo-que-no-se-mide/

- `index.html`: el tablero completo (intro guiada, nube 3D, ciudad 3D, gráficos y tabla).
- `mapa_de_lo_que_no_se_mide.ipynb`: notebook que descarga los metadatos de la API CKAN de datos.gob.ar, los analiza y genera el HTML.

Se recomienda verla en una pantalla horizontal y con conexión a internet (Three.js y las tipografías se cargan desde CDN).
